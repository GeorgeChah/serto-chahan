# Serto Chahan

**Serto Chahan** is an open-source Syriac typeface representing the classic Serto style of Syriac script. Originally created in 2009 by George Chahan in Lebanon, this font is released under the SIL Open Font License 1.1 for open-source distribution and use.

---

Font Details
* **Font Name:** Serto Chahan
* **Script / Language:** Syriac (Serto)
* **Designer:** George Chahan
* **Country:** Lebanon
* **Original Creation Year:** 2009
* **License:** [SIL Open Font License 1.1](LICENSE.txt)
